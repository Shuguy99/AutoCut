# Уникальность клипов и публикация

AutoCut не умеет гарантировать отсутствие ограничений TikTok: «теневой бан» —
неофициальный термин, а решения платформы зависят от содержания, прав на
исходник, качества и поведения аккаунта. Ниже — что инструмент делает реально,
а что остаётся на стороне автора.

## Что делает AutoCut

- чередует стили субтитров и оформления между клипами;
- добавляет хук в первые секунды;
- добавляет финальную плашку и водяной знак;
- слегка меняет кадрирование и цветокоррекцию в рамках выбранной вариативности;
- нормализует громкость до −14 LUFS;
- проверяет, насколько клипы из одной пачки похожи по тексту;
- готовит черновик подписи и хештегов для ручной публикации.

Это делает ролики из одной пачки визуально и текстово разными. Это не
«антидетект» и не обход правил платформы.

## Чего здесь нет

AutoCut сознательно не делает:

- случайный шум и «уникализацию» пикселей;
- зеркалирование и произвольную смену скорости;
- подмену метаданных, названий файлов и кодеков;
- удаление чужих водяных знаков;
- накрутку просмотров, лайков и комментариев.

Такие приёмы не решают главную причину ограничений — неуникальный или
низкокачественный контент — и могут ухудшить качество ролика.

## Настройки

### CLI

```bash
autocut run video.mp4 \
  --variation strong \
  --style auto \
  --caption-mode word \
  --watermark "@nick" \
  --no-hook \
  --no-end-card \
  --no-loudnorm \
  --no-safe-zones
```

| Флаг | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `--variation` | `off`, `subtle`, `strong` | `subtle` | сила различий между клипами |
| `--style` | `auto`, `clean`, `bold`, `karaoke`, `minimal` | `auto` | стиль субтитров |
| `--caption-mode` | `phrase`, `word` | `phrase` | фразы или подсветка слов |
| `--watermark` | строка | нет | водяной знак, например `@nick` |
| `--no-hook` | — | хук включён | убрать верхнюю плашку |
| `--no-end-card` | — | плашка включена | убрать финальную плашку |
| `--no-loudnorm` | — | включено | не нормализовать громкость |
| `--no-safe-zones` | — | включено | не поднимать текст над UI TikTok |

В веб-интерфейсе те же параметры находятся в блоке «Уникальность и
оформление».

### Что выбрать

- **Свои видео, спокойный стиль:** `--variation subtle --style clean`.
- **Нарезка интервью/подкаста:** `--variation strong --caption-mode word`.
- **Серия клипов из одного видео:** `--variation strong`, разные хуки и
  стили, публиковать не всё сразу.
- **Бренд:** `--watermark "@nick"` и финальная плашка.

## Проверка разнообразия

После рендера в папке результата появляются:

```
diversity.json
publish.json
clips/clip_01_publish.json
```

`diversity.json`:

```json
{
  "score": 0.72,
  "max_similarity": 0.28,
  "ok": true,
  "pairs": []
}
```

- `score` — 1 минус максимальная похожесть; чем выше, тем лучше;
- `max_similarity` — максимальная Jaccard-похожесть текста между клипами;
- `ok = false` — есть пара клипов с похожестью ≥ 0.6;
- `pairs` — номера похожих клипов.

Если `ok = false`, лучше заменить один из клипов или перерендерить пачку с
другими настройками, а не публиковать почти одинаковые ролики подряд.

`publish.json` содержит черновики подписей:

```json
{
  "title": "Первая фраза клипа",
  "description": "Расшифровка фрагмента…",
  "hashtags": ["#деньги", "#успех"],
  "note": "Добавьте 1–2 хештега по теме…"
}
```

Хештеги строятся по словам расшифровки. Это только черновик: проверьте смысл,
добавьте нишевые теги и не превращайте подпись в спам.

## Чек-лист перед публикацией

1. **Права.** Вы владеете исходником или имеете разрешение. Перезалив чужого
   видео без существенной переработки — главная причина ограничений.
2. **Переработка.** Для чужого контента нужен комментарий, разбор, реакция,
   монтаж или другая содержательная ценность, а не только другой шрифт.
3. **Без чужих водяных знаков.** Не публикуйте ролики со знаками других
   платформ и приложений.
4. **Один источник — не пять подряд.** Разнесите публикации по времени; не
   выкладывайте всю пачку в один день.
5. **Разные подписи.** Используйте разные хуки, описания и 1–3 уместных
   хештега. Не копируйте один и тот же набор.
6. **Качество.** 1080×1920, 30 fps, читаемый текст, нормальная громкость.
   AutoCut делает −14 LUFS, но проверьте звук на телефоне.
7. **Безопасные зоны.** Текст не должен попадать под нижние подписи и правые
   кнопки TikTok. Для этого включены `safe_zones`.
8. **Нативное видео.** Загружайте файл напрямую в TikTok, не через
   перезаливку с другим водяным знаком.
9. **Проверка аналитики.** Если охваты упали, сравните несколько последних
   роликов: возможно, дело в теме, а не в «теневом бане».
10. **Апелляция.** При явной ошибке модерации используйте штатную форму
    поддержки TikTok, а не попытки «переуникалить» файл.

## Ограничения

- Вариативность меняет оформление, но не делает чужое видео вашим.
- Онтология TikTok не публикует точных правил ранжирования; любые
  «гарантии» здесь были бы обманом.
- Проверка похожести работает по тексту, а не по аудио/видеоотпечаткам.
- Водяной знак и плашки — элементы оформления, а не защита от копирования.
