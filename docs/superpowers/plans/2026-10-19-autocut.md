# AutoCut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Локальное приложение, которое скачивает видео с YouTube (или берёт локальный файл), находит лучшие фрагменты, делает вертикальные клипы 1080×1920 с вжжёнными субтитрами и раскладывает их по папкам.

**Architecture:** Python-пакет `autocut` с независимыми модулями: загрузка, медиа-анализ, транскрипция, скоринг, субтитры, рендер, хранение. Оркестратор `pipeline.py` связывает их. CLI и FastAPI-веб используют один и тот же `run_pipeline`; веб добавляет in-memory очередь job'ов.

**Tech Stack:** Python 3.14, ffmpeg/ffprobe 8.1, yt-dlp, faster-whisper, numpy, FastAPI + Uvicorn, pydantic v2, pytest.

**Spec:** `docs/superpowers/specs/2026-10-19-autocut-design.md`

## Global Constraints

- Python ≥ 3.11; проверенная версия в окружении — 3.14.8.
- Системные `ffmpeg` и `ffprobe` обязательны; проверять на старте приложения.
- Результат: 1080×1920, 30 fps, libx264 CRF 20 preset veryfast, AAC 128 kbps 48 kHz, `+faststart`.
- Клипы: 20–60 с, по умолчанию 5 штук, целевая длина 30 с.
- Субтитры: ASS, Liberation Sans 48, белый текст, чёрная обводка 4, `MarginV=230`, ≤ 2 строк, ≤ 42 символов в строке.
- Папка результата: `output/<channel-slug>/<video_id>_<title-slug>/`, существующие папки не перезаписываются.
- Все subprocess-вызовы — только списком аргументов, без `shell=True`.
- Сеть: тесты никогда не ходят на YouTube/PyPI; сетевые вызовы только в downloader и замоканы.
- Ошибки пользователю — по-русски; технические детали — в лог.
- Веб слушает `127.0.0.1` по умолчанию.
- Каждая задача заканчивается запуском своих тестов и git-коммитом.
- YouTube с текущей машины блокируется на TLS; E2E проверяется локальным файлом.

```python
from __future__ import annotations

from dataclasses import asdict, dataclass, field
from pathlib import Path
from typing import Literal

from pydantic import BaseModel, Field, model_validator


@dataclass
class Word:
    start: float
    end: float
    text: str


@dataclass
class Segment:
    start: float
    end: float
    text: str


@dataclass
class Transcript:
    language: str
    words: list[Word]
    segments: list[Segment]
    text: str

    def to_dict(self) -> dict:
        return asdict(self)

    @classmethod
    def from_dict(cls, data: dict) -> "Transcript":
        return cls(
            language=data.get("language", "unknown"),
            words=[Word(**w) for w in data.get("words", [])],
            segments=[Segment(**s) for s in data.get("segments", [])],
            text=data.get("text", ""),
        )


@dataclass
class ClipCandidate:
    start: float
    end: float
    score: float
    parts: dict[str, float] = field(default_factory=dict)


@dataclass
class SourceInfo:
    video_id: str
    title: str
    channel: str
    duration: float
    webpage_url: str
    source_path: Path
    view_count: int | None = None


class JobOptions(BaseModel):
    clips: int = Field(5, ge=1, le=50)
    min_duration: float = Field(20, ge=1, le=120)
    max_duration: float = Field(60, ge=1, le=180)
    target_duration: float = Field(30, ge=1, le=120)
    layout: Literal["blur", "crop"] = "blur"
    proxy: str | None = None
    cookies: str | None = None
    model: str | None = None
    language: str | None = None

    @model_validator(mode="after")
    def _validate(self) -> "JobOptions":
        if self.min_duration > self.max_duration:
            raise ValueError("min_duration не может быть больше max_duration")
        self.target_duration = min(
            max(self.target_duration, self.min_duration), self.max_duration
        )
        return self
```

```python
from __future__ import annotations

import os
from dataclasses import dataclass
from pathlib import Path
from typing import Any

import yaml


@dataclass(frozen=True)
class Config:
    output_dir: Path = Path("output")
    work_dir: Path = Path("work")
    model: str = "small"
    device: str = "cpu"
    compute_type: str = "int8"
    proxy: str | None = None
    cookies: Path | None = None
    ascii_slug: bool = False
    keep_work: bool = False
    language: str | None = None
    max_height: int = 1080


_ENV = {
    "output_dir": "AUTOCUT_OUTPUT",
    "work_dir": "AUTOCUT_WORKDIR",
    "model": "AUTOCUT_MODEL",
    "device": "AUTOCUT_DEVICE",
    "compute_type": "AUTOCUT_COMPUTE_TYPE",
    "proxy": "AUTOCUT_PROXY",
    "cookies": "AUTOCUT_COOKIES",
    "ascii_slug": "AUTOCUT_ASCII_SLUG",
    "keep_work": "AUTOCUT_KEEP_WORK",
    "language": "AUTOCUT_LANGUAGE",
}

_BOOL_KEYS = {"ascii_slug", "keep_work"}


def _as_bool(value: Any) -> bool:
    if isinstance(value, bool):
        return value
    return str(value).strip().lower() in {"1", "true", "yes", "on"}


def load_config(path: Path | None = None, **overrides: Any) -> Config:
    data: dict[str, Any] = {
        "output_dir": Path("output"),
        "work_dir": Path("work"),
        "model": "small",
        "device": "cpu",
        "compute_type": "int8",
        "proxy": None,
        "cookies": None,
        "ascii_slug": False,
        "keep_work": False,
        "language": None,
        "max_height": 1080,
    }

    if path is not None and Path(path).exists():
        loaded = yaml.safe_load(Path(path).read_text(encoding="utf-8")) or {}
        data.update({k: v for k, v in loaded.items() if k in data})

    for key, env_name in _ENV.items():
        if env_name in os.environ:
            data[key] = os.environ[env_name]

    for key, value in overrides.items():
        if value is not None and key in data:
            data[key] = value

    for key in _BOOL_KEYS:
        data[key] = _as_bool(data[key])
    data["max_height"] = int(data["max_height"])
    data["output_dir"] = Path(data["output_dir"]).expanduser()
    data["work_dir"] = Path(data["work_dir"]).expanduser()
    if data["cookies"]:
        data["cookies"] = Path(data["cookies"]).expanduser()
    return Config(**data)
```

```python
from __future__ import annotations

import json
import re
import unicodedata
from pathlib import Path

from .models import Transcript

_TRANSLIT = {
    "а": "a", "б": "b", "в": "v", "г": "g", "д": "d", "е": "e",
    "ё": "e", "ж": "zh", "з": "z", "и": "i", "й": "y", "к": "k",
    "л": "l", "м": "m", "н": "n", "о": "o", "п": "p", "р": "r",
    "с": "s", "т": "t", "у": "u", "ф": "f", "х": "kh", "ц": "ts",
    "ч": "ch", "ш": "sh", "щ": "sch", "ъ": "", "ы": "y", "ь": "",
    "э": "e", "ю": "yu", "я": "ya", "і": "i", "ї": "yi", "є": "ye",
    "ґ": "g",
}


def _transliterate(value: str) -> str:
    lowered = value.lower()
    return "".join(_TRANSLIT.get(char, char) for char in lowered)


def slugify(text: str, ascii_only: bool = False, max_len: int = 60) -> str:
    value = (text or "").strip()
    if ascii_only:
        value = _transliterate(value)
        value = (
            unicodedata.normalize("NFKD", value)
            .encode("ascii", "ignore")
            .decode("ascii")
        )
    value = re.sub(r"[^\w\-]+", "-", value, flags=re.UNICODE)
    value = re.sub(r"[-_]{2,}", "-", value).strip("-_").lower()
    return value[:max_len].strip("-_") or "video"


def create_result_dir(
    output_dir: Path,
    channel: str,
    video_id: str,
    title: str,
    ascii_slug: bool = False,
) -> Path:
    channel_slug = slugify(channel or "unknown", ascii_only=ascii_slug, max_len=40)
    name = f"{slugify(video_id or 'video', ascii_only=True, max_len=30)}_" \
           f"{slugify(title, ascii_only=ascii_slug)}"
    base = Path(output_dir) / channel_slug
    candidate = base / name
    counter = 2
    while candidate.exists():
        candidate = base / f"{name}_{counter}"
        counter += 1
    (candidate / "clips").mkdir(parents=True)
    return candidate


def write_json(path: Path, data: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(
        json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8"
    )


def read_json(path: Path) -> dict:
    return json.loads(Path(path).read_text(encoding="utf-8"))


def save_transcript(path: Path, transcript: Transcript) -> None:
    write_json(path, transcript.to_dict())


def load_transcript(path: Path) -> Transcript:
    return Transcript.from_dict(read_json(path))


def _word_cues(words, max_words: int = 8, max_chars: int = 42):
    cues = []
    current = []
    for word in words:
        if current:
            pause = word.start - current[-1].end
            joined = " ".join(w.text for w in current + [word])
            if (
                len(current) >= max_words
                or len(joined) > max_chars
                or pause > 0.8
                or current[-1].text.endswith((".", "!", "?", "…"))
            ):
                cues.append(current)
                current = []
        current.append(word)
    if current:
        cues.append(current)
    return cues


def _srt_time(seconds: float) -> str:
    ms = int(round(max(0.0, seconds) * 1000))
    hours, ms = divmod(ms, 3_600_000)
    minutes, ms = divmod(ms, 60_000)
    secs, ms = divmod(ms, 1000)
    return f"{hours:02d}:{minutes:02d}:{secs:02d},{ms:03d}"


def write_srt(transcript: Transcript, path: Path) -> None:
    lines = []
    for index, cue in enumerate(_word_cues(transcript.words), start=1):
        lines.append(str(index))
        lines.append(f"{_srt_time(cue[0].start)} --> {_srt_time(cue[-1].end)}")
        lines.append(" ".join(w.text for w in cue))
        lines.append("")
    path.write_text("\n".join(lines), encoding="utf-8")
```

```python
from __future__ import annotations

import json
import re
import subprocess
from dataclasses import dataclass
from pathlib import Path

import numpy as np

FFMPEG = "ffmpeg"
FFPROBE = "ffprobe"


class MediaError(RuntimeError):
    pass


@dataclass
class MediaInfo:
    duration: float
    width: int
    height: int
    fps: float
    has_audio: bool


def _run_text(cmd: list[str]) -> str:
    proc = subprocess.run(cmd, capture_output=True, text=True)
    if proc.returncode != 0:
        raise MediaError(
            f"команда завершилась с ошибкой: {' '.join(cmd)}\n"
            f"{proc.stderr[-2000:]}"
        )
    return proc.stdout


def _run_bytes(cmd: list[str]) -> bytes:
    proc = subprocess.run(cmd, capture_output=True)
    if proc.returncode != 0:
        raise MediaError(
            f"команда завершилась с ошибкой: {' '.join(cmd)}\n"
            f"{proc.stderr.decode('utf-8', 'replace')[-2000:]}"
        )
    return proc.stdout


def probe(path: Path | str) -> MediaInfo:
    output = _run_text(
        [
            FFPROBE, "-v", "error", "-print_format", "json",
            "-show_format", "-show_streams", str(path),
        ]
    )
    data = json.loads(output)
    streams = data.get("streams", [])
    video = next((s for s in streams if s.get("codec_type") == "video"), None)
    audio = next((s for s in streams if s.get("codec_type") == "audio"), None)
    if video is None:
        raise MediaError(f"в файле нет видеодорожки: {path}")
    fps_raw = video.get("avg_frame_rate") or video.get("r_frame_rate") or "30/1"
    try:
        num, den = fps_raw.split("/")
        fps = float(num) / float(den or 1)
    except (ValueError, ZeroDivisionError):
        fps = 30.0
    return MediaInfo(
        duration=float(data.get("format", {}).get("duration") or 0.0),
        width=int(video.get("width") or 0),
        height=int(video.get("height") or 0),
        fps=fps,
        has_audio=audio is not None,
    )


def extract_audio(video: Path | str, out_wav: Path) -> Path:

    out_wav.parent.mkdir(parents=True, exist_ok=True)
    _run_text(
        [
            FFMPEG, "-y", "-v", "error", "-i", str(video),
            "-vn", "-ac", "1", "-ar", "16000", "-c:a", "pcm_s16le",
            str(out_wav),
        ]
    )
    return out_wav


def compute_rms_windows(audio: Path | str, window: float = 0.5) -> np.ndarray:
    raw = _run_bytes(
        [
            FFMPEG, "-v", "error", "-i", str(audio),
            "-f", "s16le", "-ac", "1", "-ar", "16000", "-",
        ]
    )
    samples = np.frombuffer(raw, dtype=np.int16).astype(np.float32) / 32768.0
    if samples.size == 0:
        return np.zeros(1, dtype=np.float32)
    size = max(1, int(16000 * window))
    pad = (-samples.size) % size
    if pad:
        samples = np.pad(samples, (0, pad))
    frames = samples.reshape(-1, size)
    return np.sqrt(np.mean(frames * frames, axis=1) + 1e-9).astype(np.float32)


def detect_scenes(video: Path | str, threshold: float = 0.35) -> list[float]:
    proc = subprocess.run(
        [
            FFMPEG, "-v", "info", "-i", str(video),
            "-vf", f"select='gt(scene,{threshold})',showinfo",
            "-an", "-f", "null", "-",
        ],
        capture_output=True, text=True,
    )
    return sorted(
        {round(float(m.group(1)), 3)
         for m in re.finditer(r"pts_time:([0-9.]+)", proc.stderr)}
    )

            "-i", str(video), "-frames:v", "1", "-q:v", "2", str(out_path),
        ]
    )
    return out_path
```

```python
from __future__ import annotations

import textwrap
from dataclasses import dataclass
from pathlib import Path

from .models import Word

ASS_HEADER = """[Script Info]
ScriptType: v4.00+
PlayResX: 1080
PlayResY: 1920
WrapStyle: 2
ScaledBorderAndShadow: yes

[V4+ Styles]
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Style: Default,{font},{size},&H00FFFFFF,&H00FFFFFF,&H00000000,&H80000000,-1,0,0,0,100,100,0,0,1,4,1,2,60,60,{margin},1

[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
"""


@dataclass
class Cue:
    start: float
    end: float
    text: str


def wrap_text(text: str, max_chars: int = 42, max_lines: int = 2) -> list[str]:
    lines = textwrap.wrap(
        text, width=max_chars, break_long_words=False, break_on_hyphens=False
    )
    return lines[:max_lines]


def group_words(
    words: list[Word],
    max_chars: int = 42,
    max_lines: int = 2,
    max_words: int = 5,
    max_duration: float = 4.0,
    pause: float = 0.6,
) -> list[Cue]:
    cues: list[Cue] = []
    current: list[Word] = []

    def flush() -> None:
        if not current:
            return
        text = " ".join(w.text for w in current).strip()
        lines = wrap_text(text, max_chars=max_chars, max_lines=max_lines)
        if lines:
            start = current[0].start
            end = max(current[-1].end, start + 0.8)
            cues.append(Cue(start, end, "\n".join(lines)))
        current.clear()

    for word in words:
        if current:
            gap = word.start - current[-1].end
            candidate = " ".join(w.text for w in current) + " " + word.text
            too_long = len(candidate) > max_chars * max_lines
            too_many = len(current) >= max_words
            too_slow = current[-1].end - current[0].start >= max_duration
            if gap > pause or too_long or too_many or too_slow:
                flush()
        current.append(word)
        if word.text.endswith((".", "!", "?", "…")) and len(current) >= 2:
            flush()
    flush()

    for index, cue in enumerate(cues[:-1]):
        next_start = cues[index + 1].start
        if cue.end > next_start:
            cue.end = max(cue.start + 0.3, next_start)
    return cues


def _ass_time(seconds: float) -> str:
    seconds = max(0.0, seconds)
    hours = int(seconds // 3600)
    minutes = int((seconds % 3600) // 60)
    secs = seconds % 60
    return f"{hours}:{minutes:02d}:{secs:05.2f}"


def _ass_escape(text: str) -> str:
    value = text.replace("\\", "").replace("{", "").replace("}", "")
    return value.replace("\n", r"\N")


def build_ass(
    cues: list[Cue],
    clip_start: float,
    clip_end: float,
    font: str = "Liberation Sans",
    font_size: int = 48,
    margin_v: int = 230,
) -> str:
    header = ASS_HEADER.format(font=font, size=font_size, margin=margin_v)
    events: list[str] = []
    for cue in cues:
        start = max(cue.start, clip_start)
        end = min(cue.end, clip_end)
        if end - start <= 0.05:
            continue
        events.append(
            f"Dialogue: 0,{_ass_time(start - clip_start)},"
            f"{_ass_time(end - clip_start)},Default,,0,0,0,,"
            f"{_ass_escape(cue.text)}"
        )
    return header + "\n".join(events) + "\n"


def write_ass(
    cues: list[Cue],
    path: Path,
    clip_start: float,
    clip_end: float,
    **kwargs,
) -> Path:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(
        build_ass(cues, clip_start, clip_end, **kwargs), encoding="utf-8"
    )
    return path


def _srt_time(seconds: float) -> str:
    ms = int(round(max(0.0, seconds) * 1000))
    hours, ms = divmod(ms, 3_600_000)
    minutes, ms = divmod(ms, 60_000)
    secs, ms = divmod(ms, 1000)
    return f"{hours:02d}:{minutes:02d}:{secs:02d},{ms:03d}"


def to_srt(cues: list[Cue]) -> str:
    blocks: list[str] = []
    for index, cue in enumerate(cues, start=1):
        text = cue.text.replace("\n", " ")
        blocks.append(
            f"{index}\n{_srt_time(cue.start)} --> {_srt_time(cue.end)}\n{text}\n"
        )
    return "\n".join(blocks)
```

```python
from __future__ import annotations

import numpy as np

from .models import ClipCandidate, Word

HOOK_WORDS = {
    "почему", "секрет", "ошибка", "главное", "правда", "никогда", "всегда",
    "шок", "важно", "причина", "способ", "результат", "деньги", "бесплатно",
    "быстро", "лучше", "хуже", "интересно", "представь", "смотри", "внимание",
    "why", "secret", "mistake", "never", "always", "shocking", "important",
    "reason", "how", "best", "worst", "free", "money", "fast", "result",
    "imagine", "look", "truth",
}


def sentence_boundaries(words: list[Word]) -> list[float]:
    bounds = {0.0}
    for index, word in enumerate(words):
        if word.text.rstrip().endswith((".", "!", "?", "…")):
            bounds.add(round(word.end, 3))
        if index + 1 < len(words):
            gap = words[index + 1].start - word.end
            if gap > 0.6:
                bounds.add(round(word.end, 3))
    return sorted(bounds)


def _snap(value: float, boundaries: list[float], max_shift: float) -> float:
    if not boundaries:
        return value
    nearest = min(boundaries, key=lambda b: abs(b - value))
    return nearest if abs(nearest - value) <= max_shift else value


def _window_words(words: list[Word], start: float, end: float) -> list[Word]:
    return [w for w in words if w.end > start and w.start < end]


def _speech_coverage(words: list[Word], start: float, end: float) -> float:
    if end <= start:
        return 0.0
    covered = sum(
        max(0.0, min(w.end, end) - max(w.start, start)) for w in words
    )
    return min(1.0, covered / (end - start))


def _normalize(values: list[float]) -> list[float]:
    if not values:
        return []
    low = float(np.percentile(values, 10))
    high = float(np.percentile(values, 90))
    if high - low < 1e-9:
        return [0.5 for _ in values]
    return [float(np.clip((v - low) / (high - low), 0.0, 1.0)) for v in values]


def _iou(first: ClipCandidate, second: ClipCandidate) -> float:
    inter = max(0.0, min(first.end, second.end) - max(first.start, second.start))
    union = (first.end - first.start) + (second.end - second.start) - inter
    return inter / union if union > 0 else 0.0


def find_highlights(
    duration: float,
    rms: np.ndarray,
    words: list[Word],
    scene_times: list[float],
    count: int = 5,
    min_duration: float = 20,
    max_duration: float = 60,
    target_duration: float = 30,
    step: float = 1.0,
) -> list[ClipCandidate]:
    duration = max(0.1, float(duration))
    if duration <= min_duration:
        return [ClipCandidate(0.0, duration, 1.0, {
            "energy": 1.0, "speech": 0.0, "scenes": 0.0,
            "hooks": 0.0, "completeness": 1.0,
        })]

    target = min(max(float(target_duration), min_duration), max_duration)
    target = min(target, duration)
    boundaries = sentence_boundaries(words) + [duration]

    starts = list(np.arange(0.0, max(0.01, duration - target) + 1e-6, step))
    if not starts or starts[-1] < duration - target - 1e-6:
        starts.append(max(0.0, duration - target))

    candidates: list[ClipCandidate] = []
    seen: set[tuple[int, int]] = set()
    for raw_start in starts:
        start = _snap(float(raw_start), boundaries, 3.0)
        end = _snap(float(raw_start) + target, boundaries, 4.0)
        if end - start < min_duration:
            end = min(duration, start + min_duration)
        if end - start > max_duration:
            end = start + max_duration
        if end > duration:
            end = duration
            start = max(0.0, end - target)
        if end - start < 1.0:
            continue
        key = (round(start, 2), round(end, 2))
        if key in seen:
            continue
        seen.add(key)

        window_words = _window_words(words, start, end)
        hook_hits = sum(
            1 for w in window_words
            if w.text.strip(".,!?…:;\"'()").lower() in HOOK_WORDS
        )
        scenes = sum(1 for t in scene_times if start <= t < end)
        boundary_hits = sum(
            1 for b in boundaries if start - 1.5 <= b <= start + 1.5
        ) + sum(1 for b in boundaries if end - 1.5 <= b <= end + 1.5)
        candidates.append(
            ClipCandidate(
                start=round(start, 3),
                end=round(end, 3),
                score=0.0,
                parts={
                    "energy": float(np.mean(rms)) if rms.size else 0.0,
                    "speech": _speech_coverage(window_words, start, end),
                    "scenes": min(1.0, scenes / 3.0),
                    "hooks": min(1.0, hook_hits / 6.0),
                    "completeness": 1.0 if boundary_hits >= 2 else (
                        0.5 if boundary_hits == 1 else 0.0
                    ),
                },
            )
        )

    energies = _normalize([c.parts["energy"] for c in candidates])
    for candidate, energy in zip(candidates, energies):
        candidate.parts["energy"] = energy
        candidate.score = round(
            0.40 * energy
            + 0.25 * candidate.parts["speech"]
            + 0.15 * candidate.parts["scenes"]
            + 0.10 * candidate.parts["hooks"]
            + 0.10 * candidate.parts["completeness"],
            4,
        )

    selected: list[ClipCandidate] = []
    for candidate in sorted(candidates, key=lambda c: c.score, reverse=True):
        if all(_iou(candidate, other) <= 0.3 for other in selected):
            selected.append(candidate)
        if len(selected) >= count:
            break
    return selected
```

```python
from yt_dlp import YoutubeDL

from .media import probe
from .models import SourceInfo


class DownloadError(RuntimeError):
    pass


def is_url(value: str) -> bool:
    return value.startswith(("http://", "https://"))


def _opts(**extra) -> dict:
    opts = {
        "quiet": True,
        "no_warnings": True,
        "noprogress": True,
        "noplaylist": True,
        "playlistend": 10,
        "format": "bv*[height<=1080]+ba/b[height<=1080]/b",
        "merge_output_format": "mp4",
    }
    opts.update(extra)
    return opts


def download(
    url: str,
    dest_dir: Path,
    proxy: str | None = None,
    cookies: str | Path | None = None,
    max_height: int = 1080,
) -> SourceInfo:
    dest_dir = Path(dest_dir)
    dest_dir.mkdir(parents=True, exist_ok=True)
    opts = _opts(
        outtmpl=str(dest_dir / "source.%(ext)s"),
        format=f"bv*[height<={max_height}]+ba/b[height<={max_height}]/b",
    )
    if proxy:
        opts["proxy"] = proxy
    if cookies:
        opts["cookiefile"] = str(cookies)

    try:
        with YoutubeDL(opts) as ydl:
            info = ydl.extract_info(url, download=True)
    except Exception as exc:
        raise DownloadError(f"не удалось скачать видео: {exc}") from exc

    if info.get("_type") == "playlist":
        entries = info.get("entries") or []
        if not entries:
            raise DownloadError("плейлист не содержит видео")
        info = entries[0]

    files = sorted(dest_dir.glob("source.*"))
    if not files:
        raise DownloadError("скачивание завершилось, но файл не найден")
    files.sort(key=lambda p: p.suffix == ".mp4", reverse=True)
    source_path = files[0]

    return SourceInfo(
        video_id=str(info.get("id") or "video"),
        title=str(info.get("title") or "Без названия"),
        channel=str(info.get("channel") or info.get("uploader") or "unknown"),
        duration=float(info.get("duration") or probe(source_path).duration),
        webpage_url=str(info.get("webpage_url") or url),
        source_path=source_path,
        view_count=info.get("view_count"),
    )


def prepare_local(path: str | Path, dest_dir: Path | None = None) -> SourceInfo:
    source = Path(path).expanduser().resolve()
    if not source.is_file():
        raise DownloadError(f"файл не найден: {source}")
    media = probe(source)
    digest = hashlib.sha1(
        f"{source}:{source.stat().st_mtime}".encode("utf-8")
    ).hexdigest()[:10]
    return SourceInfo(
        video_id=f"local_{digest}",
        title=source.stem,
        channel="local",
        duration=media.duration,
        webpage_url=source.as_uri(),
        source_path=source,
        view_count=None,
    )


def get_trending(
    region: str = "RU",
    proxy: str | None = None,
    cookies: str | Path | None = None,
) -> str:
    url = f"https://www.youtube.com/feed/trending?gl={region.upper()}"
    opts = _opts(extract_flat=True, format=None, noplaylist=False)
    if proxy:
        opts["proxy"] = proxy
    if cookies:
        opts["cookiefile"] = str(cookies)
    try:
        with YoutubeDL(opts) as ydl:
            info = ydl.extract_info(url, download=False)
    except Exception as exc:
        raise DownloadError(f"не удалось получить ленту популярного: {exc}") from exc
    entries = info.get("entries") or []
    if not entries:
        raise DownloadError("лента популярного пуста или недоступна")
    entry = entries[0]
    link = entry.get("webpage_url") or entry.get("url")
    if link and link.startswith("http"):
        return link
    video_id = entry.get("id")
    if not video_id:
        raise DownloadError("не удалось определить видео из ленты")
    return f"https://www.youtube.com/watch?v={video_id}"
```

```python
from __future__ import annotations

from pathlib import Path

from .models import Segment, Transcript, Word


class TranscriptionError(RuntimeError):
    pass


_MODELS: dict[tuple[str, str, str], object] = {}


def clear_model_cache() -> None:
    _MODELS.clear()


def _get_model(model_name: str, device: str, compute_type: str):
    key = (model_name, device, compute_type)
    if key not in _MODELS:
        try:
            from faster_whisper import WhisperModel
        except ImportError as exc:
            raise TranscriptionError(
                "faster-whisper не установлен; выполните pip install faster-whisper"
            ) from exc
        try:
            _MODELS[key] = WhisperModel(
                model_name, device=device, compute_type=compute_type
            )
        except Exception as exc:
            raise TranscriptionError(
                f"не удалось загрузить модель Whisper '{model_name}': {exc}"
            ) from exc
    return _MODELS[key]


def transcribe(
    audio: Path | str,
    model_name: str = "small",
    device: str = "cpu",
    compute_type: str = "int8",
    language: str | None = None,
) -> Transcript:
    model = _get_model(model_name, device, compute_type)
    try:
        raw_segments, info = model.transcribe(
            str(audio),
            word_timestamps=True,
            vad_filter=True,
            beam_size=5,
            language=language,
        )
        segments: list[Segment] = []
        words: list[Word] = []
        texts: list[str] = []
        for segment in raw_segments:
            text = (segment.text or "").strip()
            if not text:
                continue
            segments.append(Segment(float(segment.start), float(segment.end), text))
            texts.append(text)
            for word in segment.words or []:
                token = (word.word or "").strip()
                if token:
                    words.append(Word(float(word.start), float(word.end), token))
    except TranscriptionError:
        raise
    except Exception as exc:
        raise TranscriptionError(f"ошибка распознавания речи: {exc}") from exc

    return Transcript(
        language=getattr(info, "language", None) or "unknown",
        words=words,
        segments=segments,
        text=" ".join(texts).strip(),
    )
```

```python
from __future__ import annotations

import subprocess
from pathlib import Path

from .media import FFMPEG, make_preview


class RenderError(RuntimeError):
    pass


def _run(cmd: list[str], cwd: Path) -> None:
    proc = subprocess.run(cmd, capture_output=True, text=True, cwd=cwd)
    if proc.returncode != 0:
        raise RenderError(
            f"ffmpeg не смог отрендерить клип:\n{proc.stderr[-3000:]}"
        )


def render_clip(
    source: Path | str,
    start: float,
    end: float,
    ass_path: Path,
    out_path: Path,
    layout: str = "blur",
    width: int = 1080,
    height: int = 1920,
    fps: int = 30,
    crf: int = 20,
) -> Path:
    source = Path(source).resolve()
    out_path = Path(out_path).resolve()
    ass_path = Path(ass_path).resolve()
    out_path.parent.mkdir(parents=True, exist_ok=True)
    duration = max(0.1, end - start)
    subs = ass_path.name

    cmd = [
        FFMPEG, "-y", "-v", "error",
        "-ss", f"{max(0.0, start):.3f}",
        "-t", f"{duration:.3f}",
        "-i", str(source),
    ]

    if layout == "crop":
        video_filter = (
            f"scale={width}:{height}:force_original_aspect_ratio=increase,"
            f"crop={width}:{height},subtitles=filename={subs}"
        )
        cmd += ["-vf", video_filter, "-map", "0:v", "-map", "0:a?"]
    else:
        complex_filter = (
            f"[0:v]split=2[bg][fg];"
            f"[bg]scale={width}:{height}:force_original_aspect_ratio=increase,"
            f"crop={width}:{height},gblur=sigma=30[bgv];"
            f"[fg]scale={width}:{height}:force_original_aspect_ratio=decrease[fgv];"
            f"[bgv][fgv]overlay=(W-w)/2:(H-h)/2,"
            f"subtitles=filename={subs}[v]"
        )
        cmd += ["-filter_complex", complex_filter, "-map", "[v]", "-map", "0:a?"]

    cmd += [
        "-c:v", "libx264", "-preset", "veryfast", "-crf", str(crf),
        "-pix_fmt", "yuv420p", "-r", str(fps),
        "-c:a", "aac", "-b:a", "128k", "-ar", "48000",
        "-movflags", "+faststart", str(out_path),
    ]
    _run(cmd, cwd=ass_path.parent)
    if not out_path.exists() or out_path.stat().st_size == 0:
        raise RenderError("ffmpeg завершился без ошибки, но файл не создан")
    return out_path


def render_preview(video: Path | str, out_path: Path) -> Path:
    return make_preview(video, out_path)
```

```python
from __future__ import annotations

import shutil
import time
import uuid
from dataclasses import asdict
from pathlib import Path
from typing import Callable

from .config import Config
from .downloader import download, is_url, prepare_local
from .media import compute_rms_windows, detect_scenes, extract_audio, probe
from .models import ClipCandidate, JobOptions, SourceInfo
from .render import render_clip, render_preview
from .scoring import find_highlights
from .storage import (
    create_result_dir, load_transcript, save_transcript, write_json, write_srt,
)
from .subtitles import group_words, write_ass
from .transcribe import transcribe

ProgressFn = Callable[[str, float, str], None]


class PipelineError(RuntimeError):
    pass


class CancelledError(PipelineError):
    pass


def _check_cancel(is_cancelled: Callable[[], bool] | None) -> None:
    if is_cancelled and is_cancelled():
        raise CancelledError("задача отменена")


def _source_dict(info: SourceInfo) -> dict:
    value = asdict(info)
    value["source_path"] = str(info.source_path)
    return value


def _cached_transcript(cache_dir: Path, video_id: str):
    path = cache_dir / f"{video_id}.json"
    return load_transcript(path) if path.exists() else None


def run_pipeline(
    source: str,
    options: JobOptions,
    config: Config,
    progress: ProgressFn | None = None,
    is_cancelled: Callable[[], bool] | None = None,
) -> dict:
    report = progress or (lambda stage, pct, msg: None)
    output_dir = Path(config.output_dir).expanduser().resolve()
    work_root = Path(config.work_dir).expanduser().resolve()
    job_id = uuid.uuid4().hex[:12]
    work_dir = work_root / job_id
    work_dir.mkdir(parents=True, exist_ok=True)
    cache_dir = work_root / "cache" / "transcripts"
    cache_dir.mkdir(parents=True, exist_ok=True)
    log_path = work_dir / "job.log"
    result_dir: Path | None = None

    def emit(stage: str, percent: float, message: str) -> None:
        stamp = time.strftime("%H:%M:%S")
        with log_path.open("a", encoding="utf-8") as handle:
            handle.write(f"{stamp} [{stage}] {percent:.0f}% {message}\n")
        report(stage, percent, message)

    try:
        proxy = options.proxy or config.proxy
        cookies = options.cookies or (
            str(config.cookies) if config.cookies else None
        )
        model = options.model or config.model
        language = options.language or config.language

        emit("download", 2, "подготовка источника")
        if is_url(source):
            info = download(
                source, work_dir, proxy=proxy, cookies=cookies,
                max_height=config.max_height,
            )
        else:
            info = prepare_local(source)
        _check_cancel(is_cancelled)

        emit("analyze", 20, "чтение метаданных")
        media = probe(info.source_path)
        duration = media.duration or info.duration
        if duration <= 0:
            raise PipelineError("не удалось определить длительность видео")
        audio = extract_audio(info.source_path, work_dir / "audio.wav")
        rms = compute_rms_windows(audio)
        scenes = detect_scenes(info.source_path)
        _check_cancel(is_cancelled)

        emit("transcribe", 40, "распознавание речи")
        transcript = _cached_transcript(cache_dir, info.video_id)
        if transcript is None:
            transcript = transcribe(
                audio, model_name=model, device=config.device,
                compute_type=config.compute_type, language=language,
            )
            save_transcript(cache_dir / f"{info.video_id}.json", transcript)
        _check_cancel(is_cancelled)

        emit("score", 65, "поиск интересных фрагментов")
        candidates = find_highlights(
            duration, rms, transcript.words, scenes,
            count=options.clips,
            min_duration=options.min_duration,
            max_duration=options.max_duration,
            target_duration=options.target_duration,
        )
        if not candidates:
            raise PipelineError("не удалось найти подходящие фрагменты")
        _check_cancel(is_cancelled)

        result_dir = create_result_dir(
            output_dir, info.channel, info.video_id, info.title,
            ascii_slug=config.ascii_slug,
        )
        clips: list[dict] = []
        cliplist = [(index + 1, candidate)
                    for index, candidate in enumerate(candidates)]
        for index, candidate in cliplist:
            _check_cancel(is_cancelled)
            emit(
                "render", 65 + 30 * (index - 1) / len(cliplist),
                f"рендер клипа {index} из {len(cliplist)}",
            )
            try:
                clip_words = [
                    word for word in transcript.words
                    if word.end > candidate.start and word.start < candidate.end
                ]
                cues = group_words(clip_words)
                ass_path = work_dir / f"clip_{index:02d}.ass"
                write_ass(cues, ass_path, candidate.start, candidate.end)
                filename = f"clip_{index:02d}_score-{candidate.score:.2f}.mp4"
                out_path = result_dir / "clips" / filename
                render_clip(
                    info.source_path, candidate.start, candidate.end,
                    ass_path, out_path, layout=options.layout,
                )
                preview = render_preview(
                    out_path, result_dir / "clips" / f"clip_{index:02d}.jpg"
                )
                final_ass = result_dir / "clips" / f"clip_{index:02d}.ass"
                shutil.copy2(ass_path, final_ass)
                clips.append({
                    "index": index,
                    "file": str(out_path),
                    "preview": str(preview),
                    "subtitle": str(final_ass),
                    "start": candidate.start,
                    "end": candidate.end,
                    "duration": round(candidate.end - candidate.start, 3),
                    "score": candidate.score,
                    "parts": candidate.parts,
                    "text": " ".join(
                        word.text for word in transcript.words
                        if candidate.start <= word.start < candidate.end
                    ),
                })
            except CancelledError:
                raise
            except Exception as exc:  # noqa: BLE001
                emit("render", 65, f"клип {index} не удался: {exc}")
                clips.append({
                    "index": index,
                    "start": candidate.start,
                    "end": candidate.end,
                    "duration": round(candidate.end - candidate.start, 3),
                    "score": candidate.score,
                    "parts": candidate.parts,
                    "error": str(exc),
                })

        if not any("file" in clip for clip in clips):
            raise PipelineError("ни один клип не удалось отрендерить")

        save_transcript(result_dir / "transcript.json", transcript)
        write_srt(transcript, result_dir / "transcript.srt")
        write_json(result_dir / "source.json", {
            "source": _source_dict(info),
            "options": options.model_dump(),
        })
        write_json(result_dir / "metadata.json", {
            "source": _source_dict(info),
            "options": options.model_dump(),
            "duration": duration,
            "language": transcript.language,
            "clips": clips,
        })
        shutil.copy2(log_path, result_dir / "job.log")
        emit("done", 100, "готово")
        return {
            "result_dir": str(result_dir),
            "source": _source_dict(info),
            "clips": clips,
```

```python
from __future__ import annotations

import logging
import queue
import threading
import time
import uuid
from dataclasses import dataclass, field

from .config import Config
from .models import JobOptions
from .pipeline import CancelledError, run_pipeline

logger = logging.getLogger(__name__)


class QueueFullError(RuntimeError):
    pass


@dataclass
class Job:
    id: str
    source: str
    options: JobOptions
    status: str = "queued"
    stage: str = "queued"
    progress: float = 0.0
    message: str = ""
    result: dict | None = None
    error: str | None = None
    created_at: float = field(default_factory=time.time)
    cancel_event: threading.Event = field(
        default_factory=threading.Event, repr=False
    )

    def to_dict(self) -> dict:
        return {
            "id": self.id,
            "source": self.source,
            "options": self.options.model_dump(),
            "status": self.status,
            "stage": self.stage,
            "progress": self.progress,
            "message": self.message,
            "result": self.result,
            "error": self.error,
            "created_at": self.created_at,
        }


class JobManager:
    def __init__(self, config: Config, runner=run_pipeline, max_queue: int = 3):
        self._config = config
        self._runner = runner
        self._jobs: dict[str, Job] = {}
        self._lock = threading.Lock()
        self._queue: queue.Queue[Job | None] = queue.Queue(maxsize=max_queue)
        self._thread = threading.Thread(target=self._worker, daemon=True)
        self._thread.start()

    def submit(self, source: str, options: JobOptions) -> Job:
        job = Job(
            id=uuid.uuid4().hex[:12], source=source, options=options
        )
        with self._lock:
            self._jobs[job.id] = job
        try:
            self._queue.put_nowait(job)
        except queue.Full as exc:
            with self._lock:
                self._jobs.pop(job.id, None)
            raise QueueFullError("очередь заполнена, попробуйте позже") from exc
        return job

    def get(self, job_id: str) -> Job | None:
        with self._lock:
            return self._jobs.get(job_id)

    def list(self) -> list[Job]:
        with self._lock:
            jobs = list(self._jobs.values())
        return sorted(jobs, key=lambda job: job.created_at, reverse=True)

    def cancel(self, job_id: str) -> bool:
        job = self.get(job_id)
        if job is None or job.status in {"done", "failed", "cancelled"}:
            return False
        job.cancel_event.set()
        if job.status == "queued":
            job.status = "cancelled"
            job.message = "отменено до запуска"
        return True

    def shutdown(self) -> None:
        try:
            self._queue.put(None, timeout=1)
        except queue.Full:
            pass
        self._thread.join(timeout=2)

    def _worker(self) -> None:
        while True:
            job = self._queue.get()
            if job is None:
                self._queue.task_done()
                return
            try:
                if job.cancel_event.is_set():
                    job.status = "cancelled"
                    continue
                job.status = "running"
                job.stage = "start"
                job.message = "запуск"

                def progress(stage: str, percent: float, message: str) -> None:
                    with self._lock:
                        job.stage = stage
                        job.progress = float(percent)
                        job.message = message

                result = self._runner(
                    job.source, job.options, self._config,
                    progress=progress,
                    is_cancelled=job.cancel_event.is_set,
                )
                job.result = result
                job.status = "done"
                job.progress = 100.0
                job.message = "готово"
            except CancelledError:
                job.status = "cancelled"
                job.message = "отменено"
            except Exception as exc:  # noqa: BLE001
                logger.exception("job %s failed", job.id)
                job.status = "failed"
                job.error = str(exc)
                job.message = "ошибка"
            finally:
                self._queue.task_done()
```

```python
from __future__ import annotations

import asyncio
import json
from pathlib import Path
from urllib.parse import quote

from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse, HTMLResponse, StreamingResponse
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel, Field

from ..config import Config, load_config
from ..jobs import Job, JobManager, QueueFullError
from ..models import JobOptions

STATIC_DIR = Path(__file__).parent / "static"


class CreateJobRequest(BaseModel):
    source: str = Field(min_length=1)
    options: JobOptions = Field(default_factory=JobOptions)


def _job_payload(job: Job, config: Config) -> dict:
    data = job.to_dict()
    root = Path(config.output_dir).expanduser().resolve()

    def url(value: str | None) -> str | None:
        if not value:
            return None
        try:
            rel = Path(value).resolve().relative_to(root)
        except ValueError:
            return None
        return "/files/" + quote(rel.as_posix())

    if data["result"]:
        clips = []
        for clip in data["result"].get("clips", []):
            item = dict(clip)
            item["file_url"] = url(clip.get("file"))
            item["preview_url"] = url(clip.get("preview"))
            item["subtitle_url"] = url(clip.get("subtitle"))
            clips.append(item)
        data["result"] = {**data["result"], "clips": clips}
        folder = data["result"].get("result_dir")
        data["result"]["folder_url"] = url(str(Path(folder) / "metadata.json")) if folder else None
    return data


def create_app(config: Config | None = None, manager: JobManager | None = None) -> FastAPI:
    config = config or load_config()
    manager = manager or JobManager(config)
    app = FastAPI(title="AutoCut", version="0.1.0")
    app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")

    @app.get("/", response_class=HTMLResponse)
    def index() -> str:
        return (STATIC_DIR / "index.html").read_text(encoding="utf-8")

    @app.post("/api/jobs")
    def create_job(request: CreateJobRequest) -> dict:
        try:
            job = manager.submit(request.source.strip(), request.options)
        except QueueFullError as exc:
            raise HTTPException(status_code=429, detail=str(exc)) from exc
        return _job_payload(job, config)

    @app.get("/api/jobs")
    def list_jobs() -> list[dict]:
        return [_job_payload(job, config) for job in manager.list()]

    @app.get("/api/jobs/{job_id}")
    def get_job(job_id: str) -> dict:
        job = manager.get(job_id)
        if job is None:
            raise HTTPException(status_code=404, detail="job не найден")
        return _job_payload(job, config)

    @app.delete("/api/jobs/{job_id}")
    def cancel_job(job_id: str) -> dict:
        if not manager.cancel(job_id):
            raise HTTPException(status_code=404, detail="job не найден или завершён")
        return {"ok": True}

    @app.get("/api/jobs/{job_id}/events")
    def events(job_id: str) -> StreamingResponse:
        async def stream():
            last = None
            while True:
                job = manager.get(job_id)
                if job is None:
                    yield 'event: error\ndata: {"error":"job не найден"}\n\n'
                    return
                payload = json.dumps(_job_payload(job, config), ensure_ascii=False)
                if payload != last:
                    yield f"data: {payload}\n\n"
                    last = payload
                if job.status in {"done", "failed", "cancelled"}:
                    return
                await asyncio.sleep(0.4)
        return StreamingResponse(stream(), media_type="text/event-stream")

    @app.get("/files/{path:path}")
    def serve_file(path: str) -> FileResponse:
        root = Path(config.output_dir).expanduser().resolve()
        target = (root / path).resolve()
        if not target.is_relative_to(root) or not target.is_file():
            raise HTTPException(status_code=404, detail="файл не найден")
        return FileResponse(target)

    return app
```

```python
from __future__ import annotations

import argparse
import json
import os
import sys
from pathlib import Path

from .config import load_config
from .downloader import DownloadError, get_trending
from .models import JobOptions
from .pipeline import PipelineError, run_pipeline
from .transcribe import TranscriptionError


def _add_common(parser: argparse.ArgumentParser) -> None:
    parser.add_argument("--clips", type=int, default=5, help="сколько клипов сделать")
    parser.add_argument("--min", dest="min_duration", type=float, default=20)
    parser.add_argument("--max", dest="max_duration", type=float, default=60)
    parser.add_argument("--target", dest="target_duration", type=float, default=30)
    parser.add_argument("--format", dest="layout", choices=["blur", "crop"], default="blur")
    parser.add_argument("--model", default=None, help="модель Whisper (tiny/base/small/medium)")
    parser.add_argument("--language", default=None, help="язык речи (ru/en/...)")
    parser.add_argument("--proxy", default=None)
    parser.add_argument("--cookies", default=None)
    parser.add_argument("--output", default=None, help="папка результатов")
    parser.add_argument("--config", default=None, help="путь к config.yaml")
    parser.add_argument("--keep-work", action="store_true")
    parser.add_argument("--ascii-slug", action="store_true")
    parser.add_argument("--json", action="store_true", help="вывести результат в JSON")


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="autocut", description="YouTube → вертикальные клипы")
    sub = parser.add_subparsers(dest="command", required=True)

    run_parser = sub.add_parser("run", help="обработать ссылку или файл")
    run_parser.add_argument("source")
    _add_common(run_parser)

    trending = sub.add_parser("trending", help="взять верхнее видео из ленты популярного")
    trending.add_argument("--region", default="RU")
    _add_common(trending)

    web = sub.add_parser("web", help="запустить веб-интерфейс")
    web.add_argument("--host", default="127.0.0.1")
    web.add_argument("--port", type=int, default=8000)
    web.add_argument("--config", default=None)
    web.add_argument("--output", default=None)
    return parser


def options_from_args(args: argparse.Namespace) -> JobOptions:
    return JobOptions(
        clips=args.clips,
        min_duration=args.min_duration,
        max_duration=args.max_duration,
        target_duration=args.target_duration,
        layout=args.layout,
        proxy=args.proxy,
        cookies=args.cookies,
        model=args.model,
        language=args.language,
    )


def _config_from_args(args: argparse.Namespace):
    return load_config(
        Path(args.config) if args.config else None,
        output_dir=args.output,
        keep_work=True if getattr(args, "keep_work", False) else None,
        ascii_slug=True if getattr(args, "ascii_slug", False) else None,
    )


def _print_result(result: dict, as_json: bool) -> None:
    if as_json:
        print(json.dumps(result, ensure_ascii=False, indent=2))
        return
    print("\nГотово:", result["result_dir"])
    for clip in result["clips"]:
        print(
            f"  {clip['index']:02d}. {clip['start']:7.1f}–{clip['end']:7.1f} с"
            f"  score {clip['score']:.2f}  {clip['file']}"
        )


def main(argv: list[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)

    if args.command == "web":
        import uvicorn
        from .web.app import create_app
        config = _config_from_args(args)
        uvicorn.run(create_app(config), host=args.host, port=args.port)
        return 0

    config = _config_from_args(args)
    options = options_from_args(args)

    def progress(stage: str, percent: float, message: str) -> None:
        print(f"[{stage}] {percent:5.1f}% {message}", file=sys.stderr)

    try:
        if args.command == "trending":
            source = get_trending(
                region=args.region,
                proxy=args.proxy or config.proxy,
                cookies=args.cookies or config.cookies,
            )
            print(f"Выбрано видео: {source}", file=sys.stderr)
        else:
            source = args.source
        result = run_pipeline(
            source, options, config, progress=progress
        )
    except (PipelineError, DownloadError, TranscriptionError) as exc:
        print(f"Ошибка: {exc}", file=sys.stderr)
        return 1
    except KeyboardInterrupt:
        print("\nПрервано", file=sys.stderr)
        return 130
    _print_result(result, args.json)
    return 0
```

## Отклонения от плана (по факту реализации)

Всё реализовано и проверено на этой машине; что пришлось изменить против плана:

1. **Энкодер H.264 выбирается автоматически.** В Fedora-сборке `ffmpeg-free` нет `libx264`, а VAAPI (AMD Vega) и `libopenh264` на этом железе не заводятся. `autocut/media.py` проверяет кандидатов коротким 0.4-с прогоном: `libx264` → `h264_vaapi` → `h264_nvenc` → `libopenh264` → `mpeg4`. После установки полного `ffmpeg` из RPM Fusion (пакет `x264-libs`) выбирается `libx264`, CRF 20; фолбэк на `mpeg4` остаётся для машин без x264.
2. **`faster-whisper` вынесен в extra `whisper`** (`pip install -e ".[whisper]"`): стек ctranslate2/onnxruntime/av тяжёлый, ядро и тесты работают без него. Если пакета нет, `transcribe` даёт понятную ошибку.
3. **Аудио читаем сами** (`transcribe.read_pcm_wav`: WAV 16 кГц из ffmpeg → numpy). Установленный PyAV 19.0.1 не принимает `metadata_errors`, из-за чего встроенный `faster_whisper.decode_audio` падал с `TypeError`; для не-WAV входов остаётся резервный путь с шимом поверх `av.open`.
4. **Границы длительностей** в `JobOptions`: `ge=1` вместо `ge=5/10`, иначе короткое тестовое видео не обработать.
5. **NMS по доле перекрытия** относительно более короткого окна (≤ 0.3) — так формулировка спеки «пересечение > 30 %» совпадает с тестом.
6. **Энергия окна** считается по RMS внутри окна, а не по среднему по всему файлу (баг из плана).
7. **`.ass`/`.srt` отдаются как `text/plain`** — на этой системе `.ass` маппится в `audio/aac`.
8. **Превью клипа берётся в середине ближайшей к центру реплики** (`pipeline._preview_time`), а не ровно на половине длительности: иначе кадр попадал в паузу между субтитрами и превью было без них.
