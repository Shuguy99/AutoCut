# Типовые проблемы

## `ffmpeg`/`ffprobe` не найдены

```
Ошибка: команда завершилась с ошибкой: ffprobe ...
```

Установите пакет:

```bash
sudo dnf install ffmpeg ffmpeg-free   # Fedora (полный ffmpeg — RPM Fusion)
sudo apt install ffmpeg               # Debian/Ubuntu
```

Проверка: `ffmpeg -version`, `ffprobe -version`.

## Нет libx264 / клипы в плохом качестве

В Fedora-сборке `ffmpeg-free` может не быть `libx264`. AutoCut автоматически
проверяет `libx264 → h264_vaapi → h264_nvenc → libopenh264 → mpeg4` и берёт
первый рабочий. Для качества поставьте полный ffmpeg из RPM Fusion.

## Whisper не установлен

```
faster-whisper не установлен; выполните pip install faster-whisper
```

Поставьте extra:

```bash
.venv/bin/pip install -e ".[whisper]"
```

Без него можно отключить субтитры (`--no-subtitles` / галочка в вебе), но
транскрипция всё равно используется для оценки фрагментов, поэтому пайплайн
без Whisper не выполнится. Для запуска без модели нужен только рендер-тест,
а не полный `run`.

## Скачивание модели падает с `CAS Client Error`

Сбой Xet-бэкенда Hugging Face. Повторите:

```bash
HF_HUB_DISABLE_XET=1 .venv/bin/autocut run ./video.mp4
```

## RuTube/YouTube недоступны

- `502` от `/api/feed` — проверьте DNS и доступ к `rutube.ru`;
- YouTube с этой машины может быть заблокирован: используйте
  `--proxy socks5://...` или `AUTOCUT_PROXY`;
- приватные/возрастные видео требуют `--cookies cookies.txt`.

## `Очередь заполнена`

Веб-приложение принимает до 20 ожидающих задач. Дождитесь завершения или
отмените лишние. CLI запускает задачи последовательно и в очередь не ставит.

## Видео без аудиодорожки

Клипы будут созданы без субтитров; в лог пишется
`аудиодорожка отсутствует`. Это штатное поведение, а не ошибка.

## Клип не отрендерился

Задача остаётся `done`, если хотя бы один клип удался; у неудавшихся в
`result.clips` есть `error`. Полный stderr — в `job.log` результата. Частые
причины: битый исходник, закончилось место, аппаратный энкодер не работает
(выбор автоматически откатится на следующий).

## Субтитры выглядят как аудио в браузере

Сервер отдаёт `.ass`/`.srt` как `text/plain; charset=utf-8`. Если файл
скачан и открыт локально, это зависит от ассоциаций ОС.

## Порт занят

```bash
autocut web --port 8010
autocut app --port 8765   # 0 — выбрать свободный
```

## `autocut app` открыл вкладку браузера, а не окно

Не установлен pywebview и не найден Chrome/Chromium. Установите
`pip install -e ".[app]"` или `google-chrome`/`chromium`. В режиме обычного
браузера сервер живёт до `Ctrl+C` — это ожидаемо.

## Где смотреть логи

- `job.log` в папке результата;
- `work/<job_id>/job.log` при `keep_work: true`;
- stderr сервера/CLI.
